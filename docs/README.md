## 阅读建议

- 关心**为什么这么设计**：先看 M3.4 的「最大的坑」一节，那里记录了性能问题的定位方法（分段计时而不是猜）。
- 关心**笔记怎么生成**：看 M4 第三、五节，增量与语义分章的分工有实测对比表。
- 关心**界面结构**：看 M3.5，含当前界面的层级顺序与各控件行为。
