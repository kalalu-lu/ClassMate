## 二、界面现在的顺序

```
ClassMate                        [设置]
──────────────────────────────────
准备就绪
[ 开始录音 ]
┌ 实时字幕（自动占满剩余高度）┐
└────────────────────────────┘
┌ ⋮⋮ 拖动调整高度 · 往下拖到底收起 ┐  ← 点名时出现
│ 可以这样回答（3 点）            │
│ 1. …  2. …  3. …               │
│              [复制] [关闭]      │
└────────────────────────────────┘
章节（点标题跳转）
核心版本：…
```

点「设置」后，字幕与开始录音之间插入设置面板，面板里从上到下是：
**音频来源三档 → 自动识别提问开关 → 识别与AI（模型/校正/本地/AI策略）→ 音频与文件（不存/临时/保留、导出、清空、笔记、回放）→ 课堂名与热词 → 显示课堂钟点、课后二次校正**。

## 三、用经济学课语料做回归测试

```bash
# 启动后自动重放那 33 条真实字幕，10 倍速约 25 秒跑完
adb shell am start -f 0x20000000 -n com.classmate.app/.MainActivity \
  --es replay_session eco --ei replay_speed 10
```

- `--es replay_session` 支持 `eco` / `last` / `45`，都指向同一份语料；
- `--ei replay_speed` 是整数倍速，默认 8；
- 重放会先清空字幕、上下文与冷却，等于「刚要开录」的状态；
- 重放走 `QaEngine.onFinal`，所以**振动、通知、上文 80 字、云端 3 点答案、卡片位置全都会真实发生**，与会消耗 token；
- 若「自动识别提问并生成答案」是关的，重放不会命中——这是开关该有的行为。

最后一次实测（13:54，0.6.5-M3）：

```
HIT rule=请同学回答 q=下面请同学回答一下编辑报酬低减规律是什么。
answer ok latency_ms=1326 prompt_tokens=225 sentences=3
1. 编辑报酬低减规律指编辑报酬随编辑工作量增加而递减
2. 因编辑劳动具有规模经济性，固定成本可分摊到更多成果上
3. 如编辑同一丛书多部书稿时，单部书稿的报酬常低于独立书稿
```

## 四、两个行为说明

1. **旧音频未被删除**（`_audio_archive_20261109/` 里 7 个 WAV 还在），只是测试默认走经济学语料，不再调用它们。要清可以直接删目录。
2. **答案卡片被手动拖过高度后，会保持拖动后的大小**；只有下一次点名拿到新答案时才重新按内容自适应。想立刻恢复自适应，把卡片拖到收起再等下一次，或者点「关闭」。
